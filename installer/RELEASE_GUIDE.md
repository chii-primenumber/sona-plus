# Sona Plus v1.0.0

Sona Plus is the first formal release under the independent Sona Plus name and version series. It is a derivative of the original Sona project by WJZ_P, not the original project's v1.0.0 release.

## Download and installation

Download packages and SHA256SUMS.txt from [Sona Plus Releases](https://github.com/chii-primenumber/sona-plus/releases). The Windows one-click package includes official Pengu Loader v1.1.6; the plugin-only package is for existing Pengu Loader installations. Extract the ZIP before running the installer. The installed plugin folder remains `sona` to preserve existing settings and custom assets.

See the [installation guide](https://github.com/chii-primenumber/sona-plus/blob/main/installer/INSTALL.md) and [feature overview](https://github.com/chii-primenumber/sona-plus/blob/main/README.md).
